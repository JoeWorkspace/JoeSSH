# JoeSSH 定位验证稿（2026-09-16）

这是内部验证稿，不是已经提交的 Store 文案，也不是对市场需求的结论。
目标是在零预算下验证：哪一类 Windows 用户会因为一个具体任务而愿意安装 JoeSSH。

## 当前证据

- 2026-08-16 至 09-15 的 Partner Center 收购报表显示 468 次页面浏览、2 次安装、报表转化 0.43%；页面同时提示页面浏览和安装数据延迟。
- 使用报表是选择加入数据，过去 30 天显示每月活跃设备平均值 0、会话 2、平均参与 0.15 分钟，版本分布只有 1.1.22.0 的 1 台设备。它不能代表全部用户，也不能评价当前 1.1.27.0 的留存。
- 当前 Store 已发布包是 1.1.27.0 x64。向导示例主机修复仍在独立 worktree，尚未进入 Store。
- 产品已有终端、SFTP、loopback 本地转发、保存 profile 和 JSON 连接导入；没有证据表明它能直接迁移用户现有的 OpenSSH/PuTTY 等配置或代理。

## 可验证的单一假设

> 在 Windows 上管理多台 VPS、需要频繁在终端和远程文件之间切换的个人开发者或运维者，
> 会因为“把终端、SFTP 和 loopback 转发放在一个可保存的工作区”而愿意补充使用 JoeSSH。

这只是第一版假设。若受访者说自己的任务不是多 VPS，记录实际任务并调整假设，不劝其接受这句话。

## 页面首屏候选文案

**标题：** 在 Windows 上把多台 VPS 的终端和文件放在一个工作区

**副标题：** 保存连接，切换 SSH 会话，用 SFTP 处理远程文件；需要时建立只绑定本机 loopback 的端口转发。

**三点说明：**

1. 适合每天维护多台 VPS 或开发测试服务器的 Windows 用户。
2. 不需要 JoeSSH 账号；连接 profile 和工作区偏好默认保存在本机。
3. 首次连接会要求核对服务器 SHA-256 主机指纹；Public Beta 的单次 SFTP 传输上限为 25 MiB。

**行动按钮：** 从 Microsoft Store 免费安装，先用一台自己获授权的服务器完成一个小任务。

**证据边界：** 截图必须标明是 sample/fixture；不能把截图、Rust fixture 或浏览器 mock 写成真实用户连接证明。

## 可交给 Partner Center 的候选文案

这部分只是草稿，需开发者在后台核对字符限制、语言字段和实际生效日期后手动提交。

**中文短描述：**

> Windows 多 VPS SSH 工作区：在一个桌面窗口使用终端、SFTP 和本地端口转发。免费开源，无需 JoeSSH 账号，连接配置默认保存在本机。

**中文长描述首段：**

> JoeSSH 是面向 Windows 的多 VPS SSH 工作区。适合需要在几台 VPS 或开发测试服务器之间切换的开发者和个人运维者：把交互式终端、SFTP 文件操作和本地端口转发放在同一个桌面工作区。

**中文长描述候选全文：**

> JoeSSH 是面向 Windows 的多 VPS SSH 工作区。适合需要在几台 VPS 或开发测试服务器之间切换的开发者和个人运维者：把交互式终端、SFTP 文件操作和本地端口转发放在同一个桌面工作区。
>
> 你可以：
> - 在已保存的连接之间切换，使用交互式 SSH 终端运行命令。
> - 在连接的远程目录中使用 SFTP 浏览、上传和下载文件；当前 Public Beta 每次传输上限为 25 MiB。
> - 建立仅绑定本机回环地址的本地端口转发，访问远程服务。
> - 将连接配置和工作区偏好保存在本机；无需注册 JoeSSH 账号。
>
> 安全与隐私：首次连接未知服务器时，先通过可信渠道核对 SHA-256 主机密钥指纹，再决定是否信任。已保存的主机密钥发生变化时，JoeSSH 会阻止连接并提示调查。遥测与错误上报默认关闭。
>
> 开始前请准备：一台你有权访问且网络可达的 SSH 服务器、地址、端口、用户名，以及密码或私钥。JoeSSH 是 Windows 桌面客户端，不提供云服务器或托管 SSH 服务，当前仍处于 Public Beta。

**英文短描述：**

> A Windows SSH workspace for managing multiple VPS: switch between saved sessions, run commands, browse or transfer files with SFTP, and use loopback-only local port forwarding in one desktop window.

**事实限制段：**

> 首次连接未知主机前必须从可信渠道核对 SHA-256 指纹；已存主机密钥变更会阻止连接。配置和偏好默认保存在本机，无需 JoeSSH 账号。遥测和错误上报默认关闭。JoeSSH 是客户端，不托管服务器。Public Beta 的单次 SFTP 传输上限为 25 MiB。

## 五人验证规则

让受访者先独立看页面三分钟，再问“你认为它解决什么问题”“你现在用什么”“为什么换或不换”。
记录安装意愿及理由；只有愿意安装的人才继续用自己的授权主机完成真实小任务。
记录页面理解、安装意愿、独立激活、协助分钟、首个阻碍和下次会选哪个工具。
首次成功后的第 7–13 天询问自主复用；口头喜欢、配合测试和没有任务分别记录，不能混算。

五人只用于形成或否定假设，不证明 PMF。至少 2 人独立完成且至少 1 人在窗口内自主复用，才值得继续验证这条定位；否则先改页面或换细分用户，暂停新增功能。
