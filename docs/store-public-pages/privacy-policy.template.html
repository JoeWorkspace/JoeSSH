Local-first operation

JoeSSH Community is a local-first Windows application. It does not require a JoeSSH account. SSH, terminal, SFTP, and port-forwarding traffic travels between this device and the server selected by the user. The JoeSSH publisher does not receive that traffic merely because the application is used.

Information on this device

Depending on the features used, JoeSSH may store on this device:

  • language, theme, layout, onboarding, and consent preferences;
  • connection names, hosts, ports, usernames, groups, tags, favorites, and recent-connection state;
  • recent command text used by local convenience features;
  • known-host fingerprints and verification metadata; and
  • local import, export, and workspace settings.

Passwords, passphrases, and pasted private-key contents are processed in memory when supplied for a connection and are excluded from the documented profile persistence. Local data remains until the user removes it, clears application data, or removes the operating-system profile. Uninstall behavior can leave application data behind.

Connections and third parties

A selected SSH server, network operator, proxy, DNS provider, device administrator, or clipboard service may process or log information under its own policy. Microsoft processes Store acquisition, download, and update information under the Microsoft Privacy Statement. JoeSSH does not control those services.

Telemetry

Production error telemetry is not operated for this Community release. Telemetry is unavailable or off unless a later release identifies a real endpoint and processor and the user separately opts in. Connection hosts, usernames, commands, terminal output, file content, credentials, and authentication tokens are not intended telemetry fields.

Support submissions

Information placed in a public issue is provided by its author and is visible to everyone. Users must remove credentials, private infrastructure details, terminal output, and other secrets before submitting an issue. Security vulnerabilities must use the private reporting route identified by the project support page.

Sale, advertising, and children

JoeSSH Community does not sell personal information and does not use local application data for advertising. It is a technical remote administration tool and is not directed to children.

Choices and contact

Users choose which servers to contact and can remove local profiles and application data. Requests about a self-hosted server must go to that server's operator. Questions about this policy or applicable privacy rights can be sent through the privacy contact shown above.

Changes

Material changes will receive a new last-updated date and will be announced through the canonical JoeSSH repository, release notes, or an application notice as appropriate.
