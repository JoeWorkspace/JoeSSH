Support scope

JoeSSH Community is free, MIT-licensed, and community-supported. Support is provided on a best-effort basis. Downloading or using the application does not create a service-level agreement, guaranteed response time, or entitlement to private support.

The first public release line is Windows-first. Community support covers reproducible product defects, documentation errors, and installation problems involving an official JoeSSH artifact. It does not include operating a user's SSH server, recovering a third-party system, custom deployment work, incident response, or infrastructure consulting.

Report an issue

Search existing reports before opening a new issue. A useful report includes the JoeSSH version, installation source, Windows version and architecture, the smallest reliable reproduction, and expected and actual behavior. Use the public JoeSSH issue forms for non-sensitive bugs and focused feature requests.

Remove server names and addresses, usernames, commands, terminal output, paths, private keys, passwords, passphrases, bearer tokens, and other secrets before submitting text, logs, or screenshots.

Security reports

Do not disclose a vulnerability in a public issue. Follow the private reporting instructions in the JoeSSH security policy. The security route may require a GitHub account to submit a private report, but this support page and the policy itself must remain visible while logged out.

Self-hosted components

The person or organization operating a self-hosted Sync Service or Web Admin deployment is responsible for that infrastructure, access controls, backups, retention, and monitoring. Community maintainers can review a minimal reproducible software issue but cannot inspect or administer a private deployment.

Privacy and contact

Read the JoeSSH Community Privacy Policy before sending diagnostic material. The public support contact shown above is the current route for Store installation and product support. No paid-support channel is offered for this release.
