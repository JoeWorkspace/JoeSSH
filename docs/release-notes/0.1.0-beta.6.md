# JoeSSH 0.1.0-beta.6 Public Beta

JoeSSH 0.1.0-beta.6 was a Public Beta candidate for Desktop, Web Admin,
and the self-hosted Sync Service. It keeps mobile native apps in companion
preflight while the public release path focuses on a verifiable Desktop, Web
Admin, and Sync operator experience.

## Included Surfaces

- Desktop app bundles for Windows, macOS, and Linux, with formal GitHub Actions
  release evidence required for platform signing, macOS notarization where
  required, SHA256 checksums, and source provenance sidecars.
- Web Admin static deployment package with explicit same-origin admin snapshot
  proxy guidance, CSP/security headers, and rollback instructions.
- Self-hosted Sync Service package with Docker/systemd examples, durable JSON
  ledger storage, auth tokens, CORS controls, metrics auth, backup/restore
  smoke evidence, and single-writer deployment limits.

## Release Gate

The release must pass `npm run qa:release:public`, `npm run
release:publish-preflight`, SBOM verification, Desktop formal evidence
verification, Web Admin + real Sync browser smoke, Sync backup/restore smoke,
and artifact checksum verification before the GitHub Release draft is published.

## Candidate Notes

- Desktop formal evidence diagnostics now produce a handoff-only unblock report
  that records tag/HEAD state, remote ref publication, staged Desktop artifact
  coverage, signing-secret names, workflow visibility, CI runs, and check-run
  annotations.
- Desktop formal evidence preflight now fails before workflow dispatch if the
  requested release ref does not resolve to the current healthy checkout `HEAD`
  or is not published to the canonical remote.
- Local diagnostic reports and signing-secret templates are not release upload
  artifacts and must stay outside the final `reports/release/` tree.

## Known Limits

- Mobile remains in native preflight and device-smoke follow-up for this beta.
- RSA private-key authentication remains out of scope while the upstream
  RustSec timing side-channel advisory lacks a safe release path.
- The Sync JSON ledger is for single-process self-hosted deployments only.
- Public telemetry remains opt-in and must not collect SSH hosts, usernames,
  commands, paths, file names, private keys, tokens, or terminal output.
