# JoeSSH 0.1.0-beta.10 Public Beta

JoeSSH 0.1.0-beta.10 is the current Public Beta candidate for Desktop, Web
Admin, and the self-hosted Sync Service.

## Highlights

- Adds a local release authority path so Public Beta candidates can be audited,
  packaged, provenanced, and preflighted without requiring GitHub as the release
  authority.
- Keeps GitHub release support available for hosted distribution while allowing
  self-hosted/local release evidence to be the source of truth.
- Adds an explicit `web-sync-only` profile for candidates that publish Web
  Admin and Sync without public Desktop downloads, backed by Desktop exclusion
  evidence and checksum coverage.
- Adds a local-authority-only `desktop-local-unsigned` profile for Desktop beta
  staging without GitHub or signing while keeping unsigned Desktop artifacts out
  of public release evidence.
- Hardens local release provenance by binding local authority manifests,
  Desktop source sidecars or unsigned staging handoff checksums, checksums, and
  release tags to the current Git HEAD.
- Keeps SHA256 checksum coverage and `release:publish-preflight` verification
  as required evidence before any Public Beta candidate is promoted.
- Runs the full local public release gate through the real SSH fixture path,
  preserving Desktop exec, PTY, SFTP, and port-forwarding dogfood coverage.
- Keeps the Public Beta scope focused on Desktop, Web Admin, and the
  self-hosted Sync Service for the default `full` profile; mobile public
  distribution remains out of scope.

## Known No-Go Items

- Formal Desktop public artifacts still require complete platform packages and
  signing/notarization evidence before they can be treated as public release
  binaries.
- The `full` profile still requires real signed Desktop artifacts. The
  `desktop-local-unsigned` profile is local authority only, stores its Desktop
  staging report and checksum under `reports/handoff/desktop/`, and cannot place
  Desktop artifacts under `reports/release/desktop/`.
- The `web-sync-only` profile is valid only when no Desktop artifact is staged
  under `reports/release/desktop/`; unsigned Desktop staging remains internal
  dogfood/handoff evidence.
- GitHub-hosted publication remains optional for the local authority path, but
  any GitHub draft or hosted release still requires authenticated GitHub CLI
  access and release credentials.
- Public release evidence must continue to pass SBOM, checksums, provenance,
  publish preflight, dogfood, and rollback verification before Go.
- RC audit output is profile-specific, for example
  `reports/release/public-beta-rc-audit.local.desktop-local-unsigned.json`.
