# JoeSSH 0.1.0-beta.25 Source Preview and Microsoft Store Maintenance Candidate

JoeSSH `0.1.0-beta.25` is prepared as a source-only GitHub prerelease and the
source revision for a separate Windows x64 Microsoft Store maintenance update.
The intended GitHub Release provides automatically generated source archives,
does not include Desktop installers, and has zero uploaded assets. Version
preparation does not establish that a tag, Release, or binary has been
published.

The candidate maps to MSIX `1.1.25.0`, following the existing published
`1.1.22.0` Store package. The `1.1.23.0` and `1.1.24.0` qualification attempts
are superseded; their packages and evidence remain immutable and must not be
submitted or reused. A new package must be built from the exact protected
`main` revision carrying beta.25 and pass source binding, clean-machine
lifecycle, WACK, visual review, and Partner Center certification. Its expected
filename begins with `JoeSSH_1.1.25.0_x64_` and includes the source commit and
workflow-run binding.

## Included fixes

- The Microsoft Store Desktop build no longer includes the unused Windows
  self-relaunch path. The checksum-bound Tauri compatibility patch removes its
  process-launch imports while preserving normal startup and shutdown.
- The embedded Windows application manifest now includes the required
  definition identity. The build validates the source, compiled, and packaged
  manifests with the same Windows SDK manifest tool.
- Terminal safety checks reject downloaded or decoded content piped into any
  remote program. An unrelated later command does not make an earlier safe
  pipeline fail.
- Vendored Tauri source is bound to its exact upstream archive, patch, license
  texts, advisory identity, and third-party notice generation.

## Delivery and product boundaries

- Product identity remains Microsoft Store `9NK5LLMF8LHM`, Windows x64.
- The package continues to declare 15 complete UI locales. Store listing
  locales remain discoverability metadata and are not additional installed UI
  translations.
- Desktop, Web Admin, Sync Service, and Mobile version surfaces advance
  together to `0.1.0-beta.25`; this Store-only delivery does not publish
  separate Web, Sync, or Mobile binaries.
- New build evidence, legal notices, SBOMs, SHA256 checksums, and native
  verification evidence must bind the exact beta.25 candidate commit and MSIX
  bytes. Beta.23 or beta.24 evidence cannot approve beta.25.
- Microsoft certification and Store publication remain separate from source CI
  and local package generation. A version bump is not publication evidence.
- The full Desktop/Web/Sync Service public-release gate is not waived.
  `release:publish-preflight` remains blocked until a distinct multi-platform
  release has complete evidence. Mobile remains in preview, Web Admin remains
  read-only, and this update adds no hosted or paid service.

Automated accessibility coverage does not extend the historical manual
assessment. There is no WCAG, EN 301 549, or EAA conformance claim.

## Microsoft Store What's new draft

Improves Microsoft Store packaging compatibility by removing an unused desktop
self-relaunch path and tightening validation of the embedded Windows
application manifest. Strengthens terminal safety checks for downloaded or
decoded content piped into another program. This is a new `1.1.25.0` candidate;
certification and publication remain pending.
