# JoeSSH 0.1.0-beta.28 Store candidate

This corrective candidate targets Microsoft Store package `1.1.28.0` and contains the onboarding fix from the beta.27 baseline.

## Changes

- Selecting a built-in sample in the first-run guide opens an empty New connection form instead of treating fixture data as a real SSH target.
- Quick Connect keeps the user's explicit host, even when it matches a built-in sample address.
- Store release E2E coverage and exact source-surface hashes protect the behavior.

## GitHub source prerelease boundary

The GitHub record for this source revision is a **source-only GitHub prerelease**. It uses automatically generated source archives, has zero uploaded assets, and does not include Desktop installers. It makes no WCAG conformance claim. The Windows Store package is a separate candidate that must pass its own protected build, certification, and Store submission gates.
The broader public release checklist covers Desktop, Web Admin, and the Sync Service; any binary release must carry SHA256 evidence and pass `release:publish-preflight`.

## Evidence boundary

The candidate still requires a fresh protected-main build, MSIX identity and package verification, Windows App Certification Kit, Partner Center submission, certification, and clean install/upgrade evidence. Local browser tests use an IPC mock and do not prove a real SSH connection or Store installation.
