# JoeSSH 0.1.0-beta.5 Public Beta

JoeSSH 0.1.0-beta.5 was a Public Beta candidate for Desktop, Web Admin,
and the self-hosted Sync Service. It is intended for early operators who want a
local-first SSH workspace with terminal, SFTP, forwarding, team visibility, and
self-hosted sync infrastructure.

## Included Surfaces

- Desktop app bundles for Windows, macOS, and Linux, with release evidence for
  platform signing, notarization where required, and SHA256 checksums.
- Web Admin static deployment package with explicit same-origin admin snapshot
  proxy guidance, CSP/security headers, and rollback instructions.
- Self-hosted Sync Service package with Docker/systemd examples, durable JSON
  ledger storage, auth tokens, CORS controls, metrics auth, backup/restore
  smoke evidence, and single-writer deployment limits.

## Release Gate

The release must pass `npm run qa:release:public`, `npm run
release:publish-preflight`, SBOM verification, Desktop release evidence
verification, Web Admin + real Sync browser smoke, and artifact checksum
verification before the GitHub Release draft is published.

## Known Limits

- Mobile remains in native preflight and device-smoke follow-up for this beta.
- The Sync JSON ledger is for single-process self-hosted deployments only.
- Public telemetry remains opt-in and must not collect SSH hosts, usernames,
  commands, paths, file names, private keys, tokens, or terminal output.
