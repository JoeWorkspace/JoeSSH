# JoeSSH 0.1.0-beta.27 Source Preview and Microsoft Store Maintenance Candidate

JoeSSH `0.1.0-beta.27` is a source-only GitHub prerelease candidate for a
separate Windows x64 Microsoft Store maintenance update. Any GitHub Release
must contain only automatically generated source archives and zero uploaded
assets, and does not include Desktop installers. These notes do not establish
that a tag, Release, or binary is published.

The candidate maps to MSIX `1.1.27.0`. On 2026-09-11, the Microsoft public
catalog and Partner Center showed `1.1.26.0` x64 as the current package in
Submission 6. Partner Center showed no package flights and no pending product
update. Its submitted filename binds the existing source build to main
`01bf0f680001aae45b5087ef107ecf34c779500c`, workflow run `33630996084`.
The next package must retain the Store identity and have a higher version.

## Included fixes

- Keep each connected tab's terminal, SFTP state, and port forwarding alive
  while switching tabs or connecting/disconnecting another host.
- Send prepared input only to the active, ready terminal. Bind file selection,
  overwrite confirmation, and file reading to the original connection and path;
  invalidate unfinished work when that connection ends.
- Display the connected host, port, and user independently of edits to the
  saved configuration. Reuse the existing connection for duplicate requests.
- Apply one deadline to TCP, SSH handshake, and authentication, and shut down
  the transport on failure or explicit disconnect.
- Coordinate known-hosts updates across processes with short file locks,
  atomic writes, and revocation tokens that prevent stale authentication from
  restoring removed trust. Keep the existing main JSON format and provide an
  explicit [metadata recovery tool](../known-hosts-recovery.md).
- Isolate each PTY's writes and cleanup. Use one ordered output channel,
  bounded input queues, consumption acknowledgments, and protection against
  late open results and output-consumer failures.
- Update xmldom and js-yaml to reviewed patch releases. Replace the yanked
  Rust dependencies `der 0.8.0` and `wnaf 0.14.0` with `0.8.2` and `0.14.1`.
  Keep the strict online dependency audit and 95% coverage requirements.
- Update the Vitest test-tool packages to `4.1.11`, fixing
  [GHSA-82fw-gwwq-j7x9](https://github.com/vitest-dev/vitest/security/advisories/GHSA-82fw-gwwq-j7x9).
  This addresses a development-server file-read issue; the test framework is
  not shipped as an application runtime dependency.

## Delivery and verification boundaries

The Store identity, x64 architecture, package layout, minimum Windows build
`10.0.17763.0`, 15 UI locales, and application data location remain unchanged.
Version metadata advances together across Desktop, Web, Sync, and Mobile;
this update does not publish separate Web, Sync, or Mobile binaries.

The exact protected-main SHA must pass all required CI jobs. A new source
producer run requires the existing human Stage B review. Only its exact MSIX
and provenance may be used for hosted candidate checks, native WACK, clean
install, `1.1.26.0` upgrade, recovery compatibility, and UI qualification.
Historical beta.26 evidence cannot qualify beta.27. Microsoft certification
and Store publication remain separate steps; version preparation is not proof
of either. The full multi-platform `release:publish-preflight` is not waived.

Mobile remains in preview, Web Admin remains read-only, and this update adds
no hosted or paid service. Automated accessibility checks do not extend the
historical manual assessment or establish WCAG, EN 301 549, or EAA conformance.
There is no WCAG, EN 301 549, or EAA conformance claim.

## Microsoft Store What's new draft

Improves stability when using multiple SSH connections. Terminals and port
forwarding keep running when switching tabs. File uploads stay bound to the
host and path selected when the operation began. Improves connection timeouts,
host-key storage, terminal output handling, and dependency maintenance.

多连接使用更稳定：切换标签时终端和端口转发继续运行，文件上传始终绑定操作开始时的
主机和路径。改进连接超时、主机密钥存储和终端输出处理，并更新相关依赖。

Use this draft only after the exact `1.1.27.0` package passes release gates.
