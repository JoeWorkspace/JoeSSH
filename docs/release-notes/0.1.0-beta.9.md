# JoeSSH 0.1.0-beta.9 Public Beta

JoeSSH 0.1.0-beta.9 is the current Public Beta candidate for Desktop, Web Admin,
and the self-hosted Sync Service.

## Highlights

- Keeps the Public Beta scope focused on Desktop, Web Admin, and the
  self-hosted Sync Service; mobile public distribution remains out of scope.
- Adds a repeatable Public Beta dogfood evidence script and verifier for the
  top Desktop, Web Admin, Sync, rollback, and release-evidence review tasks.
- Hardens Desktop dogfood paths: stale host-key probe results are ignored, SFTP
  directory state is freshness-guarded, overwrite confirmations are pinned to
  the directory where they were created, and active port forwards are stopped
  when the backend session changes.
- Adds native Tauri SFTP path validation so traversal, control characters, bidi
  controls, and backslashes are rejected before IPC reaches the SFTP backend.
- Adds an internal-only unsigned Desktop staging report for local dogfood and
  handoff. This records SHA256, Git ref, and Windows Authenticode status without
  treating unsigned artifacts as public release evidence.
- Preserves the full public release gate, Desktop real SSH dogfood fixture,
  SBOM verification, SHA256 checksum verification, Web Admin release checks, and
  Sync Service backup/restore evidence requirements.

## Known No-Go Items

- GitHub Actions CI must complete successfully for the candidate HEAD.
- Windows and macOS signing/notarization secrets must be configured before
  formal Desktop release evidence can be generated.
- `release:provenance`, `release:provenance:verify`, and
  `release:publish-preflight` remain gated on imported formal Desktop evidence.
