# JoeSSH 0.1.0-beta.8 Public Beta

JoeSSH 0.1.0-beta.8 is the current Public Beta candidate for Desktop, Web Admin,
and the self-hosted Sync Service.

## Highlights

- Keeps the Public Beta scope focused on Desktop, Web Admin, and the
  self-hosted Sync Service; mobile public distribution remains out of scope.
- Hardens Desktop release packaging so stale bundle artifacts from prior beta
  builds are rejected before anything is staged under `reports/release/desktop`.
- Validates Desktop signing evidence before staging artifacts, so unsigned
  Windows or macOS packages cannot leave partial release files behind.
- Preserves the full public release gate, Desktop real SSH dogfood fixture,
  SBOM verification, SHA256 checksum verification, Web Admin release checks, and
  Sync Service backup/restore evidence requirements.

## Known No-Go Items

- GitHub Actions CI must complete successfully for the candidate HEAD.
- Windows and macOS signing/notarization secrets must be configured before
  formal Desktop release evidence can be generated.
- `release:provenance`, `release:provenance:verify`, and
  `release:publish-preflight` remain gated on imported formal Desktop evidence.
