# JoeSSH 0.1.0-beta.23 Source Preview and Microsoft Store Maintenance Candidate

JoeSSH 0.1.0-beta.23 is prepared as a source-only GitHub prerelease and the
source revision for a separate Windows x64 Microsoft Store maintenance update.
The intended GitHub Release provides automatically generated source archives,
does not include Desktop installers, and has zero uploaded assets. This version
preparation does not establish that a new tag, Release, or binary has already
been published.

The candidate maps to MSIX `1.1.23.0`, following the existing `1.1.22.0` Store
package. The new package must be built from the exact protected `main` revision
carrying this version and pass the existing verification and Microsoft
certification process. Its expected filename is `JoeSSH_1.1.23.0_x64.msix`.
The beta.20, beta.21, and beta.22 tags, release notes, and GitHub Releases remain
unchanged; do not reuse them or attach new binary assets to them.

## Included fixes

- Closing a local port forward now closes its active connections and pending
  connection attempts, rather than leaving those tasks running after stop.
- SSH command execution waits for the reported exit status after output EOF.
  A missing exit status or an exit signal is an error, not a successful result.
- SFTP operations preserve valid leading or trailing spaces in remote entry
  names. Blank paths and control characters remain rejected.
- Dependency updates remove the affected JavaScript build-tooling paths and
  remediate Rust findings. The reviewed GLib backport is checked against pinned
  upstream content and the official fix.
- Rust release checks require complete online advisory and yanked-package
  scans for both lockfiles and the vendored GLib registry identity. Network
  failures cannot fall back to cached-only approval. Only the exact,
  time-bounded maintenance notices in the risk register are accepted; future
  vulnerabilities and unverified vendor changes still block the gate.
- Windows signature verification loads the Security module belonging to the
  Windows PowerShell host. Git root checks recognize Windows 8.3 aliases while
  continuing to reject a different repository.
- The README now leads with the free Store install and first-connection guide.

## Delivery and product boundaries

- Product identity remains Microsoft Store `9NK5LLMF8LHM`, Windows x64.
- The package continues to declare 15 complete UI locales. The 80 localized
  Store listings are discoverability metadata, not 80 translated application
  interfaces.
- Preserve the existing host-key review, local-first configuration, explicit
  local port-forwarding controls, and 25 MiB SFTP transfer limit.
- New build evidence, SBOMs, third-party notices, and SHA256 checksums must bind
  the exact candidate commit and bytes. Older package evidence cannot approve
  this update. Microsoft certification and Store publication remain separate
  from source CI and local package generation.
- The separate full-release gate for Desktop, Web Admin, and Sync Service is
  not satisfied by this Store-only route. `release:publish-preflight` is not
  waived. Mobile stays in preview, Web Admin remains read-only, and this update
  does not introduce a hosted service or paid feature.

Automated accessibility coverage does not extend the scope of the historical
manual assessment. There is no WCAG, EN 301 549, or EAA conformance claim.
