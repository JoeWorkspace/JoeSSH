# JoeSSH 0.1.0-beta.21 Source Preview and Microsoft Store Candidate

JoeSSH 0.1.0-beta.21 is a source-only GitHub prerelease and the distinct source
revision for a separately distributed Windows x64 Microsoft Store replacement
candidate. The GitHub Release provides automatically generated source archives;
it does not include Desktop installers and has zero uploaded assets. The Store
package maps to MSIX version `1.1.21.0` and must be built from the exact protected
`main` revision that carries this version.

The GitHub `v0.1.0-beta.20` prerelease remains permanently source-only. Its tag,
release page, and zero-asset boundary are not changed or reused by this Store
candidate.

## Included closeout work

- Desktop focus and minimum-viewport accessibility fixes from beta.20.
- WCAG A/AA automated violation gates for the tested Desktop and Web surfaces.
- Mobile request timeouts, redacted malformed-JSON diagnostics, and
  dependency-risk hardening completed during the maintenance closeout.
- A free, local-first Windows Community build with SSH, terminal, SFTP, and
  local port forwarding; no paid service is introduced.

## Store boundary

- Candidate package: `JoeSSH_1.1.21.0_x64.msix`.
- Partner Center identity must match product `9NK5LLMF8LHM` exactly.
- The older `JoeSSH_1.1.12.0_x64.msix` submission is not evidence for this
  source revision and must not be presented as beta.21.
- The uploaded MSIX is an unsigned Store input until Microsoft certifies and
  Store-signs it.
- No binary is attached to the beta.20 GitHub Release.

The separate full-release gate for Desktop, Web Admin, and Sync Service has not
been satisfied by this Store-only route. In particular,
`release:publish-preflight` remains the gate for a future multi-platform binary
release and is not being waived. The final Store handoff records the exact MSIX
SHA256 and protected-main source revision independently of GitHub upload assets.

## Accessibility and commercial status

Automated accessibility checks pass for the covered surfaces, but there is no
WCAG, EN 301 549, or EAA conformance claim. Full assistive-technology,
physical-device, native-localization, and representative-user review remain
outside this final no-manual-work closeout. Any future paid offering must reopen
the legal, consumer-market, accessibility, support, and commercial readiness
gates before sale.
