# JoeSSH 0.1.0-beta.12 Public Beta

JoeSSH 0.1.0-beta.12 is the current Public Beta candidate for Desktop, Web
Admin, and the self-hosted Sync Service.

## Highlights

- Adds Web Admin triage controls for local search, attention filtering, filtered
  counts, and empty states while keeping the loaded live or fixture Sync
  snapshot as the source of truth.
- Polishes Desktop context navigation with compact icon tabs and a visible
  no-session callout that routes operators back to the Connect workflow.
- Keeps the Public Beta release path anchored on local release authority,
  profile-specific RC audit output, SHA256 checksum manifests, SBOM verification,
  rollback evidence, and `release:publish-preflight`.
- Keeps the `web-sync-only` profile available for Web Admin and Sync Service
  candidates that intentionally exclude public Desktop downloads.
- Keeps Desktop in Public Beta scope for source, dogfood, and formal evidence
  readiness, while public Desktop binaries still require signed formal artifacts
  before they can be promoted.

## Known No-Go Items

- Formal Desktop public artifacts still require complete platform packages and
  signing/notarization evidence before they can be treated as public release
  binaries.
- The `full` profile still requires real signed Desktop artifacts. The
  `web-sync-only` profile is valid only when no Desktop artifact is staged under
  `reports/release/desktop/`.
- GitHub-hosted publication remains optional for the local authority path, but
  any GitHub draft or hosted release still requires authenticated GitHub CLI
  access and release credentials.
- Public release evidence must continue to pass SBOM, SHA256 checksums,
  provenance, publish preflight, dogfood, and rollback verification before Go.
