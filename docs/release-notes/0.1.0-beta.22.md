# JoeSSH 0.1.0-beta.22 Source Preview and Microsoft Store Candidate

JoeSSH 0.1.0-beta.22 is a source-only GitHub prerelease and the distinct source
revision for a separately distributed Windows x64 Microsoft Store replacement
candidate. The GitHub Release provides automatically generated source archives;
it does not include Desktop installers and has zero uploaded assets. The Store
package maps to MSIX version `1.1.22.0` and must be built from the exact protected
`main` revision that carries this version.

The existing beta.20 and beta.21 tags and Releases remain unchanged and must not
be reused. The beta.21 MSIX uploaded to the draft Partner Center update is not
publication evidence for beta.22 and must be replaced before certification.

## Included correction

- A canonical mapping binds the 15 complete JoeSSH UI locale packs to their
  Microsoft Store BCP-47 manifest language tags.
- Unknown system locales now fall back to English instead of Simplified Chinese;
  users can still select any of the 15 complete UI languages explicitly.
- A clean-HEAD MakeAppx finalizer changes only `AppxManifest.xml/Resources`,
  verifies every other unpacked payload file byte-for-byte, and records both raw
  and final package hashes.
- Candidate preflight rejects packages whose language declaration differs from
  the reviewed UI mapping.

## Store language boundary

- Candidate package: `JoeSSH_1.1.22.0_x64.msix`.
- Partner Center identity must match product `9NK5LLMF8LHM` exactly.
- The 80 localized Store listings are discoverability metadata. They remain
  separate from installed UI support and are not represented as 80 translated
  application interfaces.
- The package declares exactly 15 complete UI locales. The other 65 Store
  listing locales continue to receive the English fallback when their system
  language does not map to a shipped UI pack.
- The uploaded MSIX remains an unsigned Store input until Microsoft certifies
  and Store-signs it.

The separate full-release gate for Desktop, Web Admin, and Sync Service has not
been satisfied by this Store-only route. `release:publish-preflight` remains the
gate for a future multi-platform binary release and is not waived.

## Accessibility and commercial status

Automated accessibility checks pass for the covered surfaces, but there is no
WCAG, EN 301 549, or EAA conformance claim. No paid service is introduced. Any
future paid offering must reopen the legal, consumer-market, accessibility,
support, and commercial readiness gates before sale.
