# JoeSSH 0.1.0-beta.19 Source Preview

JoeSSH 0.1.0-beta.19 is a source-only GitHub prerelease that closes the current
feature-development cycle. GitHub's automatically generated source archives are
the only downloads in this prerelease. It does not include Desktop installers,
mobile-store packages, hosted services, or prebuilt Web Admin and Sync binaries.

## Highlights

- Finalizes the local-first Desktop, read-only Web Admin, preview Mobile, and
  self-hosted Sync Service source baseline.
- Corrects Sync future-cursor handling and audit identity behavior, keeps Mobile
  response-body reads inside the request timeout, and redacts malformed JSON
  response contents from diagnostics.
- Narrows the temporary Mobile Expo/Metro dependency-risk exception to the exact
  reviewed graph and keeps high-severity production dependency checks fail-closed.
- Adds EAA-oriented accessibility assessment documentation and automated WCAG 2.2
  target-size, focus visibility, contrast, keyboard, and screen-reader contract
  checks without claiming formal conformance before manual assistive-technology
  evaluation is complete.
- Records the product decision to freeze speculative feature development and
  continue only maintenance, security, compatibility, accessibility-barrier, and
  bounded community work until external demand is demonstrated.

## Distribution boundary

- The remote `v0.1.0-beta.18` tag is a tag-only preflight checkpoint. Its dry
  run failed before GitHub mutation, so no Release was created; that tag will
  not be moved, reused, or given a Release page. This `beta.19` prerelease uses
  a new protected-main candidate and passing CI evidence.
- The source can be reviewed and built under the repository documentation and MIT
  license.
- No unsigned CI bundle or local candidate file is a public release artifact.
- Public Desktop installers remain blocked until an isolated release process
  supplies valid Windows signing, macOS signing and notarization, Linux package,
  checksum, provenance, and candidate-bound evidence.
- The pending Microsoft Store candidate is not certified, Store-signed, submitted,
  or published by this prerelease.
- Accessibility assessment remains in progress; this prerelease makes no WCAG,
  EN 301 549, EAA, or platform accessibility conformance claim.
- Any later binary release must publish SHA256 manifests and pass the complete
  `release:publish-preflight` workflow; this source-only prerelease does not
  weaken or substitute for that gate.

## Verification

The annotated `v0.1.0-beta.19` tag must point to the exact protected `main`
commit whose required GitHub checks passed. The prerelease must contain zero
uploaded assets; GitHub's source zip and tarball are derived from that tag.
