# JoeSSH 0.1.0-beta.29 Store reissue candidate

This candidate carries the verified beta.28 behavior and advances the
deterministic Microsoft Store package identity from `1.1.28.0` to `1.1.29.0`.
Partner Center rejected the corrected beta.28 bytes because the full package
name `Joework.JoeSSH_1.1.28.0_X64_` is already used by the active Submission 8
draft. The version change is required by the Store and does not alter the
application behavior.

## Carried-forward behavior

- Keep built-in sample hosts out of real connection onboarding and preserve an
  explicit Quick Connect target.
- Discard late host-key probe results after Connect closes and retain invalid
  explicit ports for validation.
- Serialize SFTP transfers per session, require complete listings for overwrite
  checks, and keep file pickers bound to their original session and path.
- Preserve PTY exit status after SSH EOF, report transport and signal failures,
  and keep inactive transcript history scrollable and searchable.

## GitHub source prerelease boundary

The GitHub record for this source revision is a **source-only GitHub
prerelease**. It uses automatically generated source archives, has zero
uploaded assets, does not include Desktop installers, and makes no WCAG
conformance claim. The Windows Store package is a separate candidate that
must pass its own protected build, certification, and Store submission gates.
The broader public release checklist covers Desktop, Web Admin, and Sync Service;
any binary release must carry SHA256 evidence and pass
`release:publish-preflight`.

## Verification boundary

The source build, hosted candidate, native WACK run, and Store runtime checks
must be regenerated for the exact beta.29 commit and exact `1.1.29.0` MSIX.
Partner Center upload, certification, Store signing, and clean upgrade
delivery remain separate gates. This is a source-only GitHub record with no
uploaded GitHub release assets.
