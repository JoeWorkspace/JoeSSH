# JoeSSH 0.1.0-beta.16 Public Beta

JoeSSH 0.1.0-beta.16 is the current Public Beta candidate for Desktop, Web Admin,
and the self-hosted Sync Service.

## Highlights

- Keeps the beta15 release-gate hardening: Web Admin release ZIP verification
  rejects exact forbidden public-token needles, dogfood evidence must point at a
  `go` RC audit with no blockers, and publish preflight no longer accepts an
  unhealthy Git bypass flag.
- Extends the mobile public environment guard to scan real root and mobile app
  `.env*` files, skipping `.env.example`, without printing secret values in
  logs.
- Refreshes the Rust lockfile package versions for the current candidate so
  Cargo release builds, provenance, and source tags agree on the beta16 version.
- Retains the Desktop accessibility fixes from beta15 for keyboard context
  menus, shortcut dialog focus, disabled button states, and SFTP list row
  semantics.
- Keeps the Public Beta release path anchored on local release authority,
  profile-specific RC audit output, SHA256 checksum manifests, SBOM
  verification, rollback evidence, and `release:publish-preflight`.

## Known No-Go Items

- Formal Desktop public artifacts still require complete platform packages and
  signing/notarization evidence before they can be treated as public release
  binaries.
- The `full` profile still requires real signed Desktop artifacts. The
  `desktop-local-unsigned` profile is local authority only and keeps unsigned
  Desktop builds in handoff evidence rather than public release artifacts.
- GitHub-hosted publication remains optional for the local authority path, but
  any GitHub draft or hosted release still requires authenticated GitHub CLI
  access and release credentials.
- Public release evidence must continue to pass SBOM, SHA256 checksums,
  provenance, publish preflight, dogfood, and rollback verification before Go.
