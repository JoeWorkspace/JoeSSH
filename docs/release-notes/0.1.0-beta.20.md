# JoeSSH 0.1.0-beta.20 Source Preview

JoeSSH 0.1.0-beta.20 is a source-only GitHub prerelease for the final current
maintenance closeout. GitHub's automatically generated source archives are the
only downloads. It does not include Desktop installers, mobile-store packages,
hosted services, or prebuilt Web Admin and Sync binaries, and it has zero
uploaded assets.

## Highlights

- Fixes keyboard access to the Desktop inspector's horizontal card strip at the
  supported 900 × 480 minimum window size.
- Runs Axe against all tested WCAG 2.0, 2.1, and 2.2 A/AA violations for Desktop
  and Web Admin instead of accepting moderate or minor tagged findings.
- Locks the exact minimum Desktop viewport into CI and adds negative regression
  tests that reject severity filtering.
- Makes the Web Vite configuration compatible with the native config loader's
  explicit-extension requirement.
- Records a bounded agent-assisted technical accessibility review while keeping
  the missing NVDA, VoiceOver, TalkBack, physical-device, and
  representative-user evidence explicit.
- Adds a fail-closed commercial-release trigger so a future paid launch must
  classify EU consumer distribution and reassess EAA and applicable national
  accessibility scope.

## Distribution boundary

- `v0.1.0-beta.19` remains an immutable earlier source-only prerelease. This
  release uses a new protected-main commit and a distinct annotated tag.
- The source can be reviewed and built under the repository documentation and
  MIT license.
- The self-hosted Sync Service is available from source only; this prerelease
  does not upload a prebuilt service binary or container image.
- No unsigned CI bundle or local candidate file is a public release artifact.
- This zero-asset release has no uploaded SHA256 manifest. The
  `release:publish-preflight` gate remains mandatory for a future distinct
  full-binary version and must not be used to add assets to beta20.
- Public Desktop installers remain blocked until an isolated release process
  supplies valid Windows signing, macOS signing and notarization, Linux package,
  checksum, provenance, and candidate-bound evidence.
- Checkout, paid entitlements, hosted SaaS, and paid support remain inactive.
- Accessibility assessment remains in progress. This release makes no WCAG,
  EN 301 549, EAA, native-platform, or assistive-technology conformance claim.
- Any later binary release must pass the complete artifact and publishing gates;
  this source-only prerelease does not weaken or substitute for them.

## Verification

The annotated `v0.1.0-beta.20` tag must point to the exact protected `main`
commit whose required GitHub checks passed. The prerelease must contain zero
uploaded assets; GitHub's source zip and tarball are derived from that tag.
