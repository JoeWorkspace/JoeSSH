# JoeSSH 0.1.0-beta.11 Release Candidate

JoeSSH 0.1.0-beta.11 is a Windows-first Public Beta candidate. It is not
approved for public installer or Store distribution until the remaining
candidate-bound evidence and Partner Center certification are complete. Paid
distribution remains out of scope and disabled.

## Highlights

- Ships the validated JoeSSH Desktop candidate with local-first SSH, terminal,
  SFTP, host-key verification, and local port forwarding workflows.
- Keeps the first-run experience explicit about demonstration data and the path
  to creating a real connection.
- Synchronizes the Web Admin, Mobile, and Sync Service package metadata to the same
  beta.11 candidate version.
- Expands the shared localization surface for supported languages while
  preserving readable layouts and right-to-left rendering where applicable.
- Keeps telemetry opt-in, public release documentation, dependency controls,
  and the free community Store lane fail-closed.

## Release scope

- The first public-distribution lane is JoeSSH Desktop on Windows 10/11 x64.
- Community SSH, SFTP, port forwarding, host-key verification, and core safety
  behavior remain free and open source.
- Mobile public distribution, hosted Sync, team SaaS, paid SLA, macOS
  notarization, and Linux commercial distribution are outside this candidate's
  paid support promise.

## Verification

- All required CI checks must pass on the exact candidate commit.
- Release artifacts are identified by SHA256 and must pass
  `release:publish-preflight` before a GitHub Release is drafted.
- Microsoft Partner Center certification and Store signing/hosting remain
  external approvals; this file does not claim that the app is published.
