# JoeSSH 0.1.0-beta.24 Source Preview and Microsoft Store Maintenance Candidate

JoeSSH 0.1.0-beta.24 is prepared as a source-only GitHub prerelease and the
source revision for a separate Windows x64 Microsoft Store maintenance update.
The intended GitHub Release provides automatically generated source archives,
does not include Desktop installers, and has zero uploaded assets. This version
preparation does not establish that a tag, Release, or binary has already been
published.

The candidate maps to MSIX `1.1.24.0`, following the existing published
`1.1.22.0` Store package. The local `1.1.23.0` qualification attempt is
superseded and must not be submitted or reused. A new package must be built from
the exact protected `main` revision carrying beta.24 and pass source binding,
clean-machine lifecycle, WACK, visual review, and Partner Center certification.
Its expected filename begins with `JoeSSH_1.1.24.0_x64_` and includes the source
commit and workflow-run binding.

## Included fixes

- The MSIX manifest no longer declares an obsolete Windows App Runtime package
  dependency. The packaged WebView2 bootstrap contract remains unchanged.
- Source-build output keeps its exact bytes through the private artifact
  transfer path, and Rust tool diagnostics cannot become executable paths.
- The Desktop executable now embeds a Windows application manifest that keeps
  Common Controls v6 and declares Per-Monitor V2 DPI awareness.
- Store provenance now binds both the native build script and the Windows
  application manifest. A mid-build change to either input fails the build.

## Delivery and product boundaries

- Product identity remains Microsoft Store `9NK5LLMF8LHM`, Windows x64.
- The package continues to declare 15 complete UI locales. Store listing
  locales remain discoverability metadata and are not additional installed UI
  translations.
- The free Community product keeps host-key review, local-first configuration,
  explicit loopback port-forward controls, and the 25 MiB SFTP operation limit.
- New build evidence, legal notices, SBOMs, SHA256 checksums, and native-verification
  evidence must bind the exact beta.24 candidate commit and MSIX bytes. Beta.23
  package evidence cannot approve beta.24.
- Microsoft certification and Store publication remain separate from source CI
  and local package generation. A version bump is not publication evidence.
- The full Desktop/Web/Sync Service public-release gate is not waived.
  `release:publish-preflight` remains blocked until a distinct multi-platform
  release has complete evidence. Mobile remains in preview, Web Admin remains
  read-only, and this update adds no hosted or paid service.

Automated accessibility coverage does not extend the historical manual
assessment. There is no WCAG, EN 301 549, or EAA conformance claim.
